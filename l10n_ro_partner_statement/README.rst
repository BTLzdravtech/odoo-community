Use Cases / Context
===================

Key features
============

-  **Romanian partner statement** — extends the OCA
   ``partner_statement`` module with Romania-specific adaptations for
   outstanding and activity statements.
-  **PDF and email delivery** — generate partner statements as PDF
   documents or send them directly to customer/supplier contacts via
   email.
-  **Outstanding statement customisation** — overrides
   ``_get_account_display_lines`` to adapt account display logic to
   Romanian chart-of-accounts conventions.
-  **Accounting module integration** — works alongside the standard
   ``account`` module; no additional localization package required.
-  **AGPL-3 licensed** — open-source, maintained by NextERP Romania as
   part of the NextERP-Romania/odoo-community project.

Usage
=====

To use this module, you need to be an account adviser and go to:

Accounting -> Reporting -> Romania

Salect the Sale or Purchase Journal and click on the "Print HTML" for
the HTML report or "Print PDF". From the HTML report you can download
the XLS file.
